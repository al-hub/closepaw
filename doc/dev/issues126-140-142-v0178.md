## 구현과 안전 경계

- `android.control.island.observe` → `.drag`를 기존 discovery·로컬 동의·UI mutex·durable request_id 경로에 연결했다. 새 관찰은60초 유효하고 모든 시도에서 소모된다.
- >=450ms 누름 → 이동 → 놓기는 **정확히 자신의 아일랜드 창에만 전달하는 MotionEvent 경로**다. 앱 화면/X/잠금 화면에 좌표를 주입하지 않으며 일반 화면 제스처와 분리된다. Samsung에서 OS `dispatchGesture`가 overlay를 누르는지 입증한 것은 아니다. 검증되지 않은 기존 미사용 continued-stroke helper는 제거했다.
- 세션·epoch·동의·서비스·창·물리 입력·화면 상태를 확인한다. 8px 미만 흔들림·화면 밖 이동·오래된 관찰·잘못된 세션·중복·시간 초과를 거부/중단하고 결과 불명은 재실행하지 않는다. 성공은 dispatch 접수 대신 실제 getLocationOnScreen 전후와 요청 위치 일치로 판정한다.
- 잠금/화면 꺼짐은 표시만 숨기고 세션을 새로 시작하지 않는다. 화면을 깨우거나 인증을 해제하지 않는다. 동일 소유자가 잠금 해제 뒤 상태를 복원한다. keyguard 위 X 표시를 보장하지 않으며 원격 session.end 경로는 유지한다.
- 아일랜드에 작업 내용·앱명·오류 원문을 표시하지 않는다. current session/task의 제안된 action ID만 라벨에 반영하여 지연·중복 완료를 거부한다.
- 에뮬레이터에서 실제 production operation 10회 이동/전후 좌표/재실행 거부, 10회 화면 꺼짐·복귀 동안 session/epoch 보존과 실제 창 제거, 누르는 도중 중단, 기존 단일 X/아일랜드 및 X 종료를 검증했다.
