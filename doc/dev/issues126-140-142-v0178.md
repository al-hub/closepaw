The safe production command path is `android.control.island.observe` then
`android.control.island.drag`. It injects MotionEvents into the exact attached owned island
root, with a >=450ms cancellable hold, bounded move and release. It cannot inject into apps,
X, keyguard or arbitrary coordinates. This deliberately uses a local owned-window path;
it does **not** claim AccessibilityService.dispatchGesture can target overlays on Samsung.
The previously unused continued-stroke helper was removed: no production caller established
its native overlay delivery, and keeping an unverified global injection escape hatch is unnecessary.
Ordinary app gestures retain their original pass-through policy.

The operation requires local generic-control consent and an explicitly ACTIVE session, uses the
shared UI mutex and durable request-id deduplication, and consumes an expiring observation
before any attempt. Complete island bounds, host/root/input generation and display geometry
must still match. The native loop checks session epoch, consent, service identity, lock/interactive
state, exact root and physical input every frame. Cancellation sends CANCEL to that root only.
No effect is replayed after timeout, cancellation, rejection or unconfirmed movement.
Success requires independent getLocationOnScreen before/after and the exact requested endpoint,
with at least8px displacement on one axis. X keeps its own input path and collision protection.

Island labels never render task/app/error text. Remote status is redacted at the controller.
Power/keyguard events hide the existing surfaces without starting a session or waking the display;
unlock reprojects the current state through the same owner. This conservative policy deliberately
does not promise an X above Samsung keyguard. Session status/end remain remote operations.
Local action labels accept only current-session action IDs proposed during the current task,
rejecting delayed/duplicate completions after task changes. Service restoration keeps the existing
fail-closed ended/paused policy; it never restarts an interrupted active session.
