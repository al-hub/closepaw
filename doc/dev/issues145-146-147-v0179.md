## 계측 규격

- task ID = correlation ID, step1..9, relative monotonic nanoseconds; Voice/AI clock과 직접 뺄셈하지 않는다.
- initial observation, semantic lookup, guarded action, native action, security probe, API spacing, cue wait, fingerprint traversal, fresh native validation/action, post observation, result validation.
- nested span parent/id 명시: **동일 parent의 child만 합산**. parent minus direct children = unattributed. 모든 계층 합산 금지.
- 정상 결과 trace + diagnostics 최근4개 sequence trace. 정상 metadata ring64와 분리하여 후속 화면 이벤트로 전체 trace가 유실되지 않게 한다.
- cancellation finally에서도 trace 보존. completed_steps는 확인된 단계만, in_flight_outcome_unknown은 보수적 미확인 상태. native dispatch 이후 실제 부작용 미확인과 pending local labels를 혼동하지 않는다. process death 후 trace durable 보존은 미구현이며 confirmed cancellation으로 과장하지 않는다.
- 입력 문자열/화면 텍스트/좌표/fingerprint/패키지명을 trace에 기록하지 않는다. result observation은 기존 권한 정책 그대로다.
